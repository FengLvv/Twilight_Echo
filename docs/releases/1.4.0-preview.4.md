# Twilight Echo 1.4.0-preview.4 · Windows x64

本版包含当前分轨、和弦、旋律制谱、桌面歌词、网易云与 Agent CLI 功能，以及近期修复。完整离线包保留全部当前模型与运行环境，没有进一步缩减。

## 更新

- 整理 Core 领域组装、请求分发与平台适配层，统一分析结果版本、内存预算及进程回收，保留可恢复的分析结果。
- 歌曲页分轨混音、独立和弦／旋律显示、罗马级数与简谱／五线谱；分析进度接入任务与通知，支持设置播放时自动分析。
- 修复切换分析显示、格式悬浮菜单、HiFi 边缘布局、封面切换时圆角闪变与桌面歌词／谱面描边问题。
- 网易云歌单详情接入收藏／取消收藏，搜索结果同步喜欢状态并保留服务端排序。
- 修复日语复合假名发音转换导致的制谱失败；AMLL 结构化歌词优先提取主唱，网易云回退沿用真实歌词过滤。
- 全应用 Agent CLI 与分析产物导出，可批量分析、读取和弦及带时值的曲谱。
- 更新 follow-redirects 1.16.2、qs 6.16.1 和 node-forge 1.4.1，移除已被上游修复取代的 node-forge 补丁；生产依赖审计通过。

## 下载

- 只更新播放器：下载 `TwilightEcho-1.4.0-preview.4-setup.exe`。安装器不含 Python／模型；已有分析环境可继续使用。
- 完整离线功能：下载 `TwilightEcho-1.4.0-preview.4-win-x64-full.zip.001` 至 `.005` 共五卷，以及 `Offline-Tools.zip`。解压工具包，把工具文件与五卷放在同一个目录，双击 `Merge-Offline.cmd`，按提示合并并校验；再解压生成的 ZIP，双击 `Start.cmd`。可运行 `Verify.cmd` 校验全部解压文件。
- `SHA256SUMS.txt` 提供发布附件的校验值。自带 source ZIP 对应本 Release 提交，包含 CLI harness 与插件协议源码；不含模型及个人数据。

保留分卷、合并 ZIP 与完整解压目录时建议预留 40 GB 空间；合并验证后可删除分卷再解压。双歌手分离需要支持 CUDA 的 NVIDIA GPU；其他功能的 CPU 回退速度视设备而定。

## 使用与许可

完整包无需另装 Python 或下载模型；网易云等在线服务需要网络及使用者自己的账号。无需分享个人登录、缓存或用户配置。

部分模型采用 CC BY-NC 4.0／CC BY-NC-SA 4.0；完整模型包用于非商业分享与个人学习。第三方许可见包内 `resources/music-study/THIRD_PARTY.md` 及对应组件许可证。

这是 Windows x64 预览版。已做自动回归与独立配置的实际应用验证；未覆盖每种声卡的实际试听，也未代用户执行真实账号收藏写入。

# 五线谱调号与临时升降号修正

程序：`dist/staff-key-signature/win-unpacked/TwilightEcho.exe`。

自动调性目前为整首主调的大调／小调估计：优先使用时长加权的和弦音级分布，缺少和弦时使用人声音符的调性结果，也允许手动指定。并未新增教会调式分类或分段转调识别，因此不能宣称每首歌的调性必然正确。

原排谱序列为每个音符都显式写出升、降或还原号，即使它已包含在调号中。修正后，以调号为默认状态，按小节和八度维护临时变化，只在实际变化时标记；跨小节连音延续原音高，不重复标记，也不改变后续新音符的调号状态。

使用已有《青花瓷》完整分析结果核对：和弦与旋律均自动估计为 Db 大调。“韵味被私藏”这句在手动 F 大调下需要 3 个临时降号，在自动 Db 大调下需要 0 个；谱首 Db 大调调号仍保留。这是显示拼写修正，不是移调，也不改变模型结果文件。

175 项针对性回归测试通过，包含全部 24 个大小调的调内音阶无重复临时号、跨八度作用域、还原与恢复、小节重置、跨小节连音及实际 MIDI 音高／时值校验。Vue 类型检查、生产构建、renderer 预算和 Windows 打包依赖闭包检查通过。

最终窗口测试、截图、程序哈希记录于 `docs/staff-key-signature-validation-20261031.json` 和 `.local/staff-key-evidence/`。测试使用隔离配置及静音播放，不修改实际用户配置；没有以该曲证明所有歌曲的调性识别准确率。

# 歌词简谱与桌面歌词同步验证

日期：2026-10-31。应用：`dist/lyrics-analysis-sync/win-unpacked/TwilightEcho.exe`。

## 本次行为

- 软件内歌词和桌面歌词共用 `LyricRhythmicScore`：原生排谱输出中的音符、时值、连线和对应歌词使用同一套布局，音符高亮跟随原始音频时间。
- 和弦显示、人声简谱、和弦名称／罗马级数、自动／手动调性由 Core 统一管理。两窗口可双向操作；缺少结果时，显示按钮会启动相应分析，复用已有分轨与谱面。
- 桌面歌词支持单双行、横竖排、翻译、音译、字号和配色。任务栏模式压缩为当前和弦与当前行谱面；没有歌词时可显示定时和弦。
- 切歌按播放 occurrence 重置临时显示状态，拒绝旧窗口会话操作，避免上一首的谱面留到下一首。手动调性和和弦显示方式可持久化；改变调性不重新运行模型。
- 桌面投影保留完整文字，只传当前行附近最多 5 行原生谱面。音符动画在本窗口按时钟更新，窗口隐藏或暂停时停止连续更新。

# 署名规则与人声范围联合过滤 · 2026-11-01

测试 30 首完整歌曲：原 20 首加 10 首新增样本，共 135.2 分钟。新增样本覆盖弱声、气声、长前奏、长尾奏及现场版本。曲风为人工选择的覆盖类别。

## 结果

| 方法 | 本批剔除行数 |
|---|---:|
| 原有署名规则 | 155 |
| 单独人声范围 | 101 |
| 两者重叠 | 98 |
| 时间法额外补充 | 3 |
| 联合过滤 | 158 |

这批原始输入有 1632 行。独立用网易云 JSON 格式的结构化署名作为参照，共 130 行：规则覆盖 127 行，联合覆盖 130 行。该覆盖率只适用于这批结构化署名，不代表任意歌曲的署名过滤准确率。

时间法额外剔除了《Fix You》片尾三行：音频助理、低音吉他、录音工程师。逐条对照接口原文，三行均为明确的制作署名，没有借此扩大原词表。对照原 20 首已生成谱面的 1066 行演唱文本，新增误删为 0；新增剔除的 3 行也均为署名。此结论是样本检查，不能保证所有轻声、短促人声或错误时间戳都能正确处理。

范围检测中位数 432 ms，范围 320–825 ms，包含读取原曲和人声 WAV；不包含分轨、Python 进程启动和识谱。

## 实现与边界

保留原有行首角色规则。在六轨完成后，复用人声轨，以短时能量、相对原曲能量占比、持续时间和动态范围估计活动首尾；首尾各留 0.8 秒。没有新增推理模型或显存驻留。

只剔除完全在保护范围外的首尾行；跨界行和内部间奏行保留。信号过弱、近乎恒定或无法形成可靠范围时不授权删除；若候选全会被删，也保留原规则结果。正常歌词显示及原文不改，过滤只影响识谱输入。额外删除的行 ID、理由、范围与耗时保存在真实识谱结果中，可经 Agent CLI 检查。

分轨残留、混响、现场欢呼、无词人声会把活动范围拉宽，所以时间法不能单独替代署名规则；与真实演唱同时出现的署名仍主要靠文本规则。本次是信号活动估计，不是语音内容识别或逐帧人工标注的歌声分类评测。

## 完整程序验证

新包内 5 首完成六轨、和弦、人声简谱及五线谱导出，10 份原生导出通过 MIDI/MusicXML 一致性检查。样本：Fix You、when the party's over、Stairway To Heaven、First Love、大鱼 (唱片版)。

源码测试包括 196 项 Node 回归、42 项 Python 专项测试、三个 TypeScript 工程检查与打包资源闭包检查。可运行包位于 `dist/study-vocal-boundaries/win-unpacked/TwilightEcho.exe`。

# AMLL 主唱制谱与网易云分类兜底（2026-11-01）

## 最终规则

- AMLL-compatible TTML：只从正文读取主唱文字及时间，直接识谱。跳过制作署名词表、MiniLM 分类、人声首尾过滤；头部元数据和独立伴唱不进入主唱谱面。
- 网易云定时文本回退：来源／词表 → MiniLM 单行分类 → 人声首尾联合裁决 → 识谱。
- MiniLM 只提出候选。候选行与估计的人声活动区间相交时保留；只有完全落在活动区间外的候选，才可缩小原先 0.8 秒安全余量。随后首尾过滤继续剔除明显在保护范围外的行。
- 人声范围不确定时，模型不能授权删除；也不会因模型判定把所有输入删空。不使用语音转文字。

“人声活动区间”指检测到的首个人声活动开始至最后结束，内部间奏仍受保护。0.8 秒余量不是已确认有人声的区间，模型与时间证据共同支持时才会在其中删除。这仍不能保证任何歌曲都没有误删。

## 修复的声部问题

原来只要歌词含非主唱声部就拒绝整次识谱。现在沿用解析器的主唱／伴唱结构，提取与桌面显示一致的主唱声部，使用主唱自己的时间和词级结束时间，并保留原显示行编号。没有主唱的独立伴唱行不生成主唱谱面，显示内容保留。

播放器原先用“主唱＋伴唱”的整行文字去匹配主唱谱面，会导致谱面无法挂上；现在共享主唱选择逻辑，谱面的文字身份与主唱一致。桌面投影也保留主唱的开始与结束边界。

# 简谱字体与五线谱显示验证

日期：2026-10-31。程序目录：`dist/score-display/win-unpacked/`。

## 行为

- 简谱数字、休止符、延音线和和弦字母统一使用项目已有的 Inter。升降号使用专用音乐字形，在数字左上方单独定位，不再缩小整个音符。中文歌词沿用歌词字体设置。
- 开启乐谱后，在调性下拉菜单选择“简谱”或“五线谱”。主窗口和桌面歌词共享格式状态，格式持久化；切歌仍重置临时显示开关。
- 五线谱使用固定版本 abcjs 6.7.2 排谱，直接读取缓存中的音高、量化节拍和逐词映射。调性、谱式切换不触发分轨、模型推理或重新对齐歌词。
- 两种谱面均按原始音频秒数高亮音符；量化节拍只决定谱面的时值和间距。跨小节时值用连音线连接，音符身份保留。
- 五线谱仅在接近可视区域时排版，按行显示；桌面横排、竖排窗口和任务栏布局均支持。竖排窗口内的五线谱仍保持标准横向排谱。
- 五线谱沿用当前分析流程的四拍量化分组，本次未新增拍号识别，也未重新评价模型的转录准确率。

## 验证

- Core、Node、Vue 类型检查通过。
- 172 项针对性回归测试通过。五线谱新增测试覆盖全部 24 个大小调、跨八度音高、精确量化时值、前置休止、跨小节连音、原词标点与格式参数校验。
- 《青花瓷》442 个音符、68 行谱面使用已有真实分析结果。开发版和最终 Windows 目录包均完成窗口验证。
- Chromium 字体查询确认数字实际使用 Inter，升降号使用 Segoe UI Symbol。简谱不再因带升降号而改变数字字号。
- 窗口测试验证两端谱式、调性双向同步，相同歌词行的原始音符时间集合一致，五线谱逐音高亮随播放器时钟变化。
- 主窗口中五线谱保持原音高；主调只决定调号与音符拼写，不移调。测试通过排谱库独立生成的 MIDI 事件核对音高与时值。
- 桌面五线谱在横排、竖排和任务栏模式下的 SVG 边界均位于对应歌词槽内。保留翻译、音译、单双行、倍速时钟、锁定策略和切歌清理。
- 切换谱式和调性后，`notation-result.json` 的修改时间不变，确认复用模型结果。
- 生产构建、renderer 资源预算、255 个打包依赖闭包、Python 分析资源闭包检查通过。
- 最终包运行和关闭均无页面错误。开发测试关闭时曾记录到既有 `syncExtensions` 退出请求报错；未将其描述成谱面运行错误，也未修改插件生命周期。
- 测试使用隔离用户目录、静音播放，未修改真实用户配置，未进行实际扬声器听测。

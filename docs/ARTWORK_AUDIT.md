# 封面链路与缓存排查

日期：2026-10-29。所有写入、断网和重启验证使用隔离配置；日常配置只读取了缓存设置与文件数量，没有删除或改写。

## 本机证据与根因

- 日常封面缓存已开启；标准配置的 `music-cache/cover-cache` 中有 522 个 `.remote` 图片文件。
- 老版本只有按图片地址散列存储的图片，没有歌曲身份到图片地址的索引。仅剩歌曲 ID 的队列/历史快照无法在断网冷启动时找到这些文件。
- 听歌排行从统计数据只提取 `displayTrack`，丢弃了统计行的 `cover`；统计仪表盘和首页使用相同数据，因此应统一修复适配器。
- `CoverImg` 同时收到图片与 `coreTrackId` 时，曾无条件忽略图片；曲库不包含该在线歌曲时会显示空封面。
- 界面将一次失败缓存为当前曲库版本内的永久空值；确定性图片句柄重新授权后，又可能因为 URL 没变而无法重试。
- 首次下载虽然写入了缩略图，返回界面的仍是原始大图。缓存故障也不应使有效的网络图片失败。

## 缓存约定

- Core 先用提供的封面，再读私有歌曲索引，最后按准确歌曲 ID 补取。网易云详情请求批量化；第三方搜索只接受相同音源、相同歌曲 ID。
- 远程索引位于封面缓存目录的 `track-artwork` 子目录，按音源和歌曲 ID 散列命名，保存原始图片地址，不保存音频地址、登录凭据或会话图片句柄。
- 远程索引与普通图片采用 7 天有效期；内存成功结果 5 分钟，失败结果 30 秒。本地曲库图片重新向曲库读取，避免旧封面覆盖修改后的图片。
- 关闭封面缓存时不读取或写入索引；清理封面缓存会连同索引清理，并等待已开始的写入结束。
- 有明确许可到期时间的图片不写入身份索引或永久图片缓存；上游 `no-store` 等策略仍适用于图片字节。
- 第一次显示也优先返回已缩小的缓存图片。磁盘读写失败时保留有效的在线图片；取消请求仍然取消。
- 旧图片缓存不会被清空：已知图片地址可直接命中；缺少身份映射的历史记录需要联网补齐一次，之后才能凭歌曲身份离线恢复。

## 验证边界

`test:artwork` 汇总封面、搜索、历史、缓存和真实 Electron 图片组件测试。关键冷启动测试会重新创建 Core 解析器、授权服务及磁盘缓存实例，再阻断网络；同一首歌的详情查询与图片下载计数必须不增加。

实际新包验证使用合成收听记录和匿名可访问的真实网易云歌曲 ID。为了显示账号门禁后的排行入口，测试只在隔离渲染器内设置 UI 登录状态；没有使用真实账号、Cookie，也没有执行收藏或其他账号写入。此验证不能代表真实账号排行榜接口的在线可用性。

详细输出：`output/artwork-audit-tests.log`、`output/artwork-audit-extra-tests.log`、`output/artwork-audit-ui.log`，界面证据与机器可读结果位于 `output/playwright/artwork-audit`。

# 日语长音发音转换修复

日期：2026-11-02；版本：1.4.0-preview.3。

## 复现与根因

日常 profile 的《春灯》（`ncm:1824900296`）六轨和和弦已完成，旋律阶段失败：`歌词发音转换失败："Script token 'aa' not found in script-to-phoneme dict."`。

歌词中的「あぁしたいような」「あぁあぁ」经过 kana 表得到 `aa`，实际 TiFA 日语字典只有基础音节，没有该复合读音。使用同一模型环境直接转换可复现原异常。全表检查还发现 157 个不同的复合读音没有直接字典项。

## 修复

- `JapaneseKanaConverter` 优先保留字典原有读音；仅对 kana 表声明的缺失读音，按已有音节和辅音组合出完整音素路径。例如 `aa → a + a`、`kaa → ka + a`。保留字典多读音候选及原词／分组身份，不删除歌词或省略未知发音。
- 收紧片假名转平假名的 Unicode 范围，避免把长音符 `ー` 错误偏移成半浊点 `゜`，使 `ーぁ` 等已有条目能够正常匹配。
- 未更换模型、未修改共享环境或字典；有效读音与既有成功缓存保持不变。失败任务没有旋律成功缓存，重试只需继续失败阶段。

## 验证

- 36 项日语／多语言／对齐／排谱回归通过，包含实际本机发音模型库；补充断言后 6 项日语测试再次通过。
- 安装包自带转换器通过全部 330 个 kana 条目，全部 157 个原先没有直接字典项的读音均可转换。
- 只读复制《春灯》的原曲和已有六轨人声，在独立目录重跑完整旋律流程：7 个上下文组均实际计算，315 个音符、15 行简谱生成成功；两行「あぁ」均生成，15 行原歌词逐行比对保持一致。总耗时约 158 秒，包括冷导入、节拍、音高和排版，不代表热态速度或识谱准确率。
- 生产构建、renderer 预算、Windows 品牌和 255 包依赖闭包检查通过。安装包转换器与源码 SHA-256 一致。
- 没有改写日常 profile、没有替换或关闭用户正在使用的旧程序；更新并重新启动后才会使用修复。

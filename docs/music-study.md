# 歌曲分析

正在播放页面的「分析歌曲」是分轨模式开关，右上方常驻的「和弦」也可启动分析，不需要创建项目。后台分析进度统一从右上角查看；关闭歌曲页面或关闭分轨模式不取消任务。

## 使用

简谱以每句实际人声起止为边界，保留弱起、不完整尾小节和句内休止；不再用 `0` 补齐每句首尾。软件歌词、桌面歌词和曲谱导出共用该谱面。音符识别缓存 `vocal-notes.json` 与谱面缓存 `vocal-score.json` 独立，排版失效只重新排版；未发布的旧合并缓存和阶段推断兼容路径已移除。

1. 播放一首歌，展开歌曲页面，点击「分析歌曲」。封面位置变成六轨音量面板，歌词、歌曲信息和底部控制保持原位。首次在「分析环境」中选择包含 `runtime`、`models` 的环境目录；准备检查在后台进行。
2. 默认先分离鼓、贝斯、吉他、钢琴、其他乐器、人声。六轨完成后立即在当前播放位置接管音源，接着用贝斯、钢琴、吉他、其他轨识别和弦，不等待和弦才切换。在线歌曲须完整缓存；试听片段会被拒绝。
3. 和弦完成后自动显示歌词上方的和弦，随同一播放时钟高亮、滚动。右上方可切换「和弦名称／罗马级数」，例如 `C–Am–F–G` 显示为 `I–vi–IV–V`。级数按整首和弦推断的主调换算，也可手动选择调性；无歌词时显示同步和弦列表，无时间歌词显示当前和弦。模型和主调估计均可能出错，可听辨校正。
4. 人声轨右侧「多人声拆分」包含两个独立操作：「主唱／和声分离」「双歌手分离」。选择后才运行，复用六轨人声。完成后子轨显示在人声下方；可切换回总人声。两组子轨互斥，父人声音量、静音和独听作为所选子轨的总线控制。
5. 所有轨共用原播放器的播放、暂停、进度和主音量。滑杆、独听和静音直接更新原生混音增益，不重新解码或重新排队。「分析歌曲」激活时显示选中态，再点一次取消分轨模式，在最新位置恢复封面和原曲；暂停时保持暂停。准备阶段也可取消激活，后台任务继续。再次进入已分析歌曲会复用结果及保存的混音设置，但普通切歌仍先播放原曲。
6. 面板右上角更多操作可导出所选 24-bit WAV/FLAC，以及 TXT/CSV/JSON 和弦；也可校正和弦标签及相邻边界、按需识别原曲作为对照、配置环境、清除结果。导出包含人工校正，并写入独立目录。
7. 右上方「简谱」独立识别人声主旋律。未分轨时先准备六轨，已有结果直接复用人声，不额外识别和弦或拆分多人声。识别完成后在每句歌词上方显示音符、升降号和八度点，随播放高亮；再次点击隐藏，再开启复用结果。可在旁边显示方式菜单中选择调性；小调采用关系大调的 `1`，以 `6` 为主音。旋律转写复用现有离线 SheetSage2/MERT2 模型，只取人声旋律轨；重叠演唱时显示主旋律，结果需要听辨核对。

「分析歌曲」的选中底色、图标与封面／分轨面板采用交叠过渡；降低动画时仅保留淡入淡出，关闭动画时直接切换。右侧歌词栏保持原位，过渡不延迟音频控制。

混音面板沿用播放器的透明背景、图标按钮与弹出菜单，人声及其子轨置顶。进入分析仅替换封面区域，歌词栏保持原来的几何位置；面板在可用的左侧留白内加宽。每个歌词行的和弦位置由该行的时间范围固定，播放仅改变高亮；`N`（无和弦）不显示为标签。原曲与分轨切换先预解码目标音源，同采样率 PCM 复用已打开的输出设备，在当前时间接管；采样率、声道布局或 DSD 路由变化时仍走完整设备协商，保持原曲格式。

右上角「分析进度」每首歌仅显示歌名和状态图标：转圈表示识别中，勾号表示已识别；失败或中断使用提示图标，可点击继续／重试，识别中的图标可点击取消。任务按请求顺序串行执行，重复点击不重复创建。重启后未完成任务标记中断；和弦失败或取消时，已完成六轨仍可使用。已完成且输入、模型及文件摘要一致的阶段会复用，完整缓存后可离线重试。分析音频缓存仅服务于该歌曲分析，不建立集中网易云资料库。

## 安装独立分析环境

应用安装包不包含 Python、CUDA 或模型权重。开发源码下执行：

```powershell
winget install astral-sh.uv
.\scripts\install-music-study.ps1 -Root D:\Tools\TwilightEchoToolchain\study -Device cuda
```

也可用 `-UvPath` 指定 uv 可执行文件。脚本创建 Python 3.11 环境，安装固定版本依赖及 PyTorch 2.8 CUDA 12.8，下载校验后的模型，并将两个固定来源的训练权重转换为推理用 safetensors。安装阶段需要网络及数 GB 空间；下载和转换暂存还会占用额外空间。高精度和弦的 SheetSage2 与 MERT-v2 权重额外约 2.76 GB，代码与权重为 **CC-BY-NC-4.0，限非商业使用**。分析阶段在本机运行，不向模型服务上传歌曲。乐器分离与和弦有 CPU 路径；双歌手功能要求 CUDA GPU。

选择上述根目录，或在启动前设置 `TWILIGHT_MUSIC_STUDY_HOME`。用户选择的路径保存在当前用户配置中的 `music-study/environment.json`。项目数据库为 `music-study/projects.sqlite`，音频及各阶段缓存位于同目录下的项目子目录。

模型登记见 [models.json](../resources/music-study/models.json)，模型来源和许可证见 [THIRD_PARTY.md](../resources/music-study/THIRD_PARTY.md)。更换权重需同时更新登记、安装器和验证结果；不能只替换同名文件。

## 实现边界

- Renderer 只发送有类型的 Core 命令并读取投影。Core 管理项目状态、任务串行调度、恢复、人工编辑、监听和导出策略。
- Main 提供受约束的文件授权、原生目录选择、音源缓存和固定 Python worker 启动能力。Core 中不导入 Node/Electron。
- `worker.py` 默认执行 Demucs 六轨，再执行 SheetSage2 / MERT-v2 伴奏和弦识别，原子发布每个阶段结果；MDX 主唱/和声与 Duet 双歌手为独立的按需任务。阶段缓存包含输入、模型和输出摘要；不完整或损坏文件不会当作成功结果复用。原 BTC、ChordMini 和色度融合实现保留用于相同输入的比较。
- 模型目录只读取固定摘要的权重和配置；Python 架构随应用固定打包，不执行模型包内脚本。HF 网络访问在 worker 中关闭。首次大文件校验在后台运行，项目查询与已有结果不等待环境检查。
- `.temix` 清单由原生解码线程读取，各轨使用独立解码缓冲，由同一个渲染时钟按相同帧位置混合；增益通过原子快照与短渐变更新，渲染线程不读取磁盘。
- 单次最长 3 小时。v1 双歌手分离至多两位，A/B 只是跨片段的匿名音色标记，不识别真实身份。
- 双歌手模型本身为单声道 24 kHz；为同步监听对齐为 44.1 kHz 双声道，不代表恢复原始立体声或高频。其他轨也可能有串音和分离伪影。
- 提供名称／罗马级数显示及主调选择，不包含 MIDI、钢琴卷帘、完整扒谱或逐段功能和声／转调分析。名称切换与主调选择只影响显示，不改写识别结果，也不会重新运行模型。

## 验证与效果

本次歌曲内交互已验证六轨先切换、和弦后自动开启、主播放器定位与暂停恢复、实时音量、名称／罗马级数切换、后台任务顺序及阶段失败后的六轨复用。完整 3:51 歌曲在本机 RTX 5080 的本次阶段记录为六轨约 7.4 秒、和弦约 14.1 秒；首次环境检查、Python 启动与音源准备另计，不代表点击后的总等待时间。多人声任务的阶段复用另通过真实模型及文件时间戳验证。

本机使用 RTX 5080 验证真实模型推理、应用内监听/定位/循环/人工校正/导出；同时验证 HTTP 完整缓存、断网重分析和取消进程。自动化配置与用户正常播放器配置隔离。

Windows 目录运行版通过 254 项依赖的闭包检查、原生 Core 首次/冷启动与无窗口播放测试，以及随包 worker 的 CUDA 检查。真实界面复测包含浅色、深色、窄窗口、独听/静音和人工校正；导出的十条 24-bit FLAC 均为 44.1 kHz 双声道且帧数一致，CSV 包含已保存的人工标签。原文件移走后，新平台实例仍能用已保存副本继续分析。

完整曲目、论文/仓库、固定修订、五方案指标和局限见 [本机比较报告](music-study-comparison-20261030.md)；摘要和各指标有效时长见 [JSON](music-study-comparison-20261030.json)。GuitarSet 详细性质参考有效约 1,860.53 秒，占总音频约 69.6%；保留集只是本次选择过程中的保留，不能排除公开预训练语料交叉。输入是原始伴奏录音，**不包含上游分轨误差**。这些详细性质指标忽略转位低音，不能与大小调归并或转位准确率混用。网易云没有人工真值，九首通过仅证明流程运行；自动化试听为零音量，不构成人耳听音验收。

仓库现有的 `core-boundaries` 检查有三项基线失败，涉及评论模块的 Node 导入、`Buffer` 和既有 Legacy port 数量；在未加本功能的隔离基线上也复现相同失败。本次分轨 Core 服务只使用业务层和共享协议，没有增加这些边界违规。

双歌手模型可用于真实分离，但效果取决于音色、重叠和录音；相似声音仍可能串音或交换。ECAPA 音色匹配稳定 A/B 顺序，并在含糊区间给出提示，不保证所有歌曲身份完全稳定。较长的两个复核样本分别为约 21 秒和 7.5 秒，均无检测到的身份交换；这不是全曲保证。

复现脚本位于 `resources/music-study/benchmark_chords.py`、`evaluate_harmony.py` 和 `evaluate_duet.py`；研究评测额外依赖见 `requirements-benchmark.txt`。评测音频、模型和私有缓存不随源码或安装包分发。数据来源：[GuitarSet](https://zenodo.org/records/3371780)、[IDMT](https://zenodo.org/records/7544213)、[MedleyVox](https://zenodo.org/records/7984549)。

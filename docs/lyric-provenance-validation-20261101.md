# 歌词来源与声学评分实验（2026-11-01）

结论：TiFA 相似度不能可靠判断给定文字是否被演唱。评分已从正式分析流水线、结果类型、缓存和 CLI 接入中撤下，仅保留离线实验工具。正式功能为来源过滤、原有署名词表与人声首尾范围，不引入新的识别模型。

## 当前行为

歌词解析保留 `origin: {format: 'netease-json', kind: 'metadata' | 'unknown'}`。网易云负时间的静态元数据按来源排除，不依赖职业名称；正时间或缺少有效时间的结构化文字保持 `unknown`，不会因为 JSON 格式就全部删除。来源经过共享解析、歌词行构造、Core 冻结及 Python 校验，普通播放器和桌面歌词仍保留原文。

原有署名词表和人声首尾范围规则继续工作。明确元数据在分层推断前分开，避免被同时间的不同文字系统误判成翻译层。

实验工具沿用 TiFA 推理得到的音素／音频相似度，在 WordList 的最小时长修补之前采集原始对齐区间，逐行测量音素数量、实际对齐覆盖率、原始余弦相似度、正分比例、单帧挤压比例、歌词时间窗口重叠和复核原因。没有新增模型或 ASR。

实验中的 `measured` 只表示完成测量；`review` 表示存在对齐异常，不能解释为“制作署名”。正式结果不包含这些测量和判定。

## 50 首来源链路检查

读取前两批保存的 50 首完整歌曲接口原文，共 2,925 条候选行。9 条有明确静态元数据来源，269 条为时间语义未定的结构化行；这 9 条也已被现有词表覆盖，因此本批来源层额外剔除 0 条。Core 与 Python 的完整行选择、模型键和策略哈希一致。

此前可逐条对照的 278 条结构化制作信息中，词表与人声范围仍覆盖 277 条。《Shape of You》的 `Mixed at The Mixsuite (South London and Los Angeles)` 保持未自动剔除；没有为提高本批数字而把所有正时间 JSON 当作元数据。

## 声学对照实验

6 首歌曲的 7 段真实人声片段（《白日》在独立分轨结果中重复验证），每段选择两行，分别配正确歌词、错配歌词、制作署名和静音音频，共 28 次片段推理、56 条行级测量。歌曲为《群青》《打上花火》《白日》《如愿》《Shape of You》《when the party's over》。

| 输入 | 行数 | 平均相似度范围 | 被标记复核 |
| --- | ---: | --- | ---: |
| 正确歌词 | 14 | 0.59780–0.75707 | 0 |
| 错配歌词 | 14 | 0.41424–0.63038 | 0 |
| 制作署名 | 14 | 0.39308–0.64850 | 0 |
| 静音 + 原歌词 | 14 | -0.18565–-0.01521 | 14 |

正确歌词与错配文字的分布重叠。强制对齐甚至会为未唱的制作署名生成完整音素路径，覆盖率接近 1；对齐成功与正余弦分数都不足以证明文本被演唱。因此本次没有启用声学自动删除阈值。

这些是有限片段的对照，不能作为跨曲风、跨语言分类准确率。后续自动判别需要独立验证证据，例如疑难片段的识别文本对照；本次未引入额外识别模型。

撤下评分前，使用实验包、独立静音测试配置执行六轨、去人声和弦分析、歌词对齐、音高识别、简谱与五线谱导出：

| when the party's over | 246 | 28 | 0 | 5,574 |

共 2,246 个音符、244 行评分、8 份原生谱面导出。MIDI／MusicXML 回读一致性通过。流程成功不等于音高、和弦或时间对齐准确率验证。

《Shape of You》的 6 条复核行包含上述署名和 5 条正常重复演唱歌词。复核标记反映挤压或偏离时间窗口，进一步说明不能据此删除原文。

实验还验证了 4 首评分的重启恢复及 CLI 时间窗口查询，并用真实任务验证相同上下文的 4 组音符与评分可复用、无需重新对齐或识别音高。这些接入因判别能力不达标已撤下，正式版不存储评分数据。

正式旋律算法升级为 `vocal2midi-tifa-game-medium-rhythm-v7`，用于来源语义变更；旧旋律需要重新分析，六轨与和弦缓存可继续复用。

撤下评分后另用全新配置验证正式包：《如愿》完成六轨、和弦、识谱和两种导出，332 个音符、42 行谱面，2 份导出的 MIDI／MusicXML 回读一致。结果明确不含声学评分字段，测试程序已正常退出。

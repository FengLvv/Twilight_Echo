## 已知漏项与更通用的方法

《Shape of You》仍有一行未被组合策略排除：

> Mixed at The Mixsuite (South London and Los Angeles)

它没有冒号，未命中职业前缀规则；开始于 231.356 秒，而人声检测结束于 230.82 秒，0.8 秒安全余量保留到了 231.62 秒，所以时间规则也保留了这一行。另外三条无冒号的出版、录音与母带说明由时间规则排除。

这些行在接口原文中来自结构化 JSON 片段，而解析后仅剩时间和文字。下一步应保留来源信息：有明确制作信息语义的记录直接排除；不能仅凭 JSON 格式就断言一定不是演唱歌词。

没有明确来源标记的普通歌词，应结合人声活动与音频／文本匹配证据。现有 TiFA 提供音频与音素的相似度，但当前代码未把它校准为可用于拒绝歌词的分数。强制对齐返回成功不代表文本确实被演唱。需要用轻声、拖音、合唱、说唱和混合语言样本校准，再决定是否拒绝；本轮没有实施这项架构变化。

- Core 与 Python 共用同一制作信息策略；职业规则仍要求行首已知名称和冒号，版权声明仅完整行匹配。

- 2,925 条候选行在 Core／Python 中分类完全一致，模型键与策略哈希跨运行时一致。
- 198 项 Node 测试、43 项 Python 测试，以及 Core／Main／Renderer 三组 TypeScript 检查通过。
